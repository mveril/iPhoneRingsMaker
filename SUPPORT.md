# Support

Use [GitHub Discussions](https://github.com/mveril/iPhoneRingsMaker/discussions) for usage questions and troubleshooting. Use [GitHub Issues](https://github.com/mveril/iPhoneRingsMaker/issues) for reproducible defects and focused feature requests.

Before asking for help, review the requirements and known limitations in the [README](README.md). Include the application version, Windows version, device model, connection method, relevant logs, and exact reproduction steps. Remove personal media information and device identifiers before posting.
