# Privacy Policy

iPhoneRingsMaker processes selected audio files, project files, application settings, and information exposed by connected Apple devices locally on the Windows computer.

The application does not include analytics, advertising, user accounts, or a project-operated remote service. It does not intentionally transmit media, device information, or usage data to the project maintainer.

The application may open external documentation in the default browser when requested. Windows, Apple device software, package managers, and third-party dependencies may operate under their own privacy policies.

Local application data can be removed through Windows application settings or by uninstalling the application and deleting retained application data. Review source changes and release notes before installing a new version because this policy may evolve with the application.
