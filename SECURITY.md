# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older builds are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository instead.

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Please allow a reasonable remediation period before public disclosure.
